# Exact versions, so a Streamlit Cloud rebuild installs the same code that was
# tested here rather than whatever is newest on the day it builds. Verified
# together on Python 3.13 (2026-09-02).
#
# Every pin here has a prebuilt Linux wheel for both 3.13 and 3.14, so the build
# does not depend on which interpreter Cloud hands out. That is why numpy is on
# 2.3.5 rather than something older: pandas 3.0.3 requires numpy>=2.3.3 on 3.14,
# and numpy 2.2.x has no 3.14 wheel at all, so an older pin makes Cloud compile
# numpy from source and hang. Check wheel coverage before lowering any of these.
#
# This freezes our side only. Yahoo and the SEC are outside it: when Yahoo
# changes its option endpoint the fix is a newer yfinance, so bump that line
# rather than assuming a pin protects it. The quarterly check compares these
# against the versions it last verified.
